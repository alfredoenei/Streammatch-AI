## 🔗 Overview / Resumen

StreamMatch AI is a next-generation platform designed to eradicate "Choice Paralysis" in the streaming world. Utilizing a curated AI engine, the platform acts as a digital Sommelier that understands your tastes, active platforms, and mood to deliver the perfect recommendation with deep narrative justification.

## 🇪🇸 Versión en Español

### 🚀 El Proyecto
StreamMatch AI no es un buscador de películas convencional. Es un ecosistema inteligente que prioriza la **curaduría narrativa** sobre los simples algoritmos de filtros. El sistema integra el "Radar de Precisión", una herramienta conversacional que desglosa tus intenciones y las cruza en tiempo real con la disponibilidad real en tus servicios de suscripción (Netflix, HBO, Disney+, etc.).

### ✨ Características Destacadas
- **IA Curatorial (The Sommelier)**: Motor de recomendación con "Doctrina AI-First" que proporciona justificaciones basadas en atmósfera, tono y equipo técnico.
- **Radar v16.4 (Conversacional)**: Interfaz de búsqueda semántica capaz de entender peticiones complejas como *"Algo de ciencia ficción de los 90 que no sea demasiado oscura"*.
- **Symmetry UI v21.0**: Diseño premium con "Aura Dinámica" que extrae colores de los posters en tiempo real para una inmersión total.
- **Resiliencia & Circuit Breaker**: Arquitectura robusta que maneja errores de red y saturación de APIs externas (429 handling) sin comprometer la UX.
- **Modo Fiesta**: Sincronización instantánea de bibliotecas entre amigos para encontrar qué ver en grupo.

### 🛠️ Stack Tecnológico & Arquitectura
- **Frontend**: React 19 + Vite + Tailwind CSS + Framer Motion.
- **Backend**: Node.js & Express (Arquitectura de Servicios desacoplada).
- **IA**: OpenAI API (System Prompt v22.0) con lógica de elasticidad y mapeo de intención semántica.
- **APIs Integradas**: TMDB (Metadatos), Watchmode (Streaming Links), Trakt (Identidad & Desambiguación).

## 🇺🇸 English Version

### 🚀 The Project
StreamMatch AI is a next-gen recommendation engine built to kill decision fatigue. It transforms the way you discover content by replacing generic lists with **expert-level AI narration**. The platform knows what you have, what you like, and why you should watch your next favorite title.

### 🌟 Key Features
- **Narrative Curation**: Advanced AI system that explains *why* a movie fits your current mood and technical tastes.
- **Smart Radar**: Conversational search engine that processes natural language into precise cross-platform queries.
- **Symmetry UI**: High-end glassmorphism design with real-time color extraction and fluid animations.
- **Architectural Resilience**: Built-in Circuit Breakers and smart caching to handle external API instability gracefully.
- **Party Mode**: Real-time platform synchronization to find common ground between friends.

### ⚙️ Tech Stack & Architecture
- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS.
- **Backend**: Express.js, Mongoose, JWT Authentication.
- **AI Engine**: Advanced Prompt Engineering for semantic intent mapping and elastic alternatives.
- **Integrations**: Multi-source identity resolution (TMDB, OMDB, Trakt, Watchmode).

## 🛠️ Instalación / Installation

1. Clona el repositorio / Clone the repo:
```bash
git clone https://github.com/alfredoenei/Streammatch-AI.git
```

2. Configura las variables de entorno en `/backend/.env` y `/frontend/.env` (revisa los `.env.example`).

3. Lanza el proyecto / Launch the project:
```bash
# Backend
cd backend && npm install && npm run dev
# Frontend
cd frontend && npm install && npm run dev
```
